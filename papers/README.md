# Papers and Reading Notes

Use this directory for reading notes, bibliographic metadata, and only
those full-text papers that you are permitted to store and redistribute.

## Suggested layout

``` text
papers/
  reading-notes/
    YYYY-author-short-title.md
  bibliography.bib
```

Guidelines:

-   Respect copyright, publisher terms, and each paper's license.
-   When redistribution is not permitted, store the citation, DOI or
    official URL, and your own notes instead of the PDF.
-   For each paper, record its main mechanism, assumptions, baselines,
    metrics, limitations, and relevance to ATLAS.
-   Keep source claims separate from your interpretation.
